Prism 的四层骨架

任何一段 Prism 代码都由这四层拼起来。第一集我们照葫芦画瓢用了一遍，这一集把它们的边界画清楚。

module
算法层
端口 + 组合/时序逻辑
@schedule
调度层
位宽 / 流水 / 存储 / 时钟 / 复位
design
组装层
实例 + connect + wire
run
仿真层
stim + until + show

算法层只写"做什么"——电路函数本身；调度层再补"怎么做"——把它下降成什么样的寄存器拓扑、多宽、几级流水。这个"两层"是 Prism 与纯 HDL 最大的差别：Verilog / VHDL 里两件事是糊在一起的，而 Prism 强制你分开。

本集所有例子在 prism/docs/blog/examples/types.prism。一条命令复现：

bashshell
python3 $PRISM_HOME/frontend/prism.py run \
    prism/docs/blog/examples/types.prism

端口与 Signal<T>

Prism 里"对外接口"用 Signal<T> 声明。T 是类型，最常见的是 u<N> / i<N> / bool。

u8 / u32
[0, 2^N − 1]
N 位无符号。位向量、地址、数据字。
i8 / i32
[−2^(N−1), 2^(N−1) − 1]
N 位有符号（补码）。带符号立即数、算术右移源。
bool
{true, false}
独立布尔类型，与 1 位整数有细微语义差。
i1
{−1, 0}
陷阱：1 位补码里最高位既是数据也是符号——写 1 会越界。
u1
{0, 1}
控制位、valid/enable 首选——不是 i1。
为什么 1 位有符号是 {−1, 0}？

补码里 N 位整数范围是 [−2^(N−1), 2^(N−1)−1]。代入 N=1：[−1, 0]。i1 只能取 −1（0b1）或 0（0b0）——仓库里谓词/条件码习惯用这个域，a == b 结果是 −1（真）或 0（假）。要写 0/1 就用 u1。

语法层面 Prism 要求端口一行一个——不像 C 的 int a, b, c;。这是刻意的：一行一端口在 diff 与语法高亮上都更清晰。

实验 ① · u8 与 i8 的溢出对撞

同样两个 100 相加，落到不同符号域里，显示的数值不一样。这是理解类型系统的最短路径。

prismtypes.prism
module u8_add {
    a   : Signal<u8>
    b   : Signal<u8>
    sum : Signal<u8>
    sum = a + b
}

module i8_add {
    a   : Signal<i8>
    b   : Signal<i8>
    sum : Signal<i8>
    sum = a + b
}
▸ u8_run
cycle a b sum 0 100 55 155 1 100 100 200 2 200 100 44 # 300 & 0xFF = 44，无符号回绕
▸ i8_run
cycle a b sum 0 100 55 -101 # 155 → 155-256 = -101 1 100 100 -56 # 200 → 200-256 = -56 2 -100 -100 56 # -200 → -200+256 = 56

两次的位模式完全一样——都是 100 + 55 = 0x9B、100 + 100 = 0xC8、-100 + -100 = 0x38。差异只在把这些位再解释成十进制时按符号性走哪条路：u8 走 [0, 255]，i8 走 [−128, 127]。

编译器帮你钉住符号性

从这一版 Prism 开始，run 输出的每一列都会按源端口的 u/i 分别用 wrap_unsigned 或 wrap_signed 回绕——不再"所有列一律按有符号打印"。所以本集里 u8 sum 打印 44 而不是 −212，i8 sum 打印 −56 而不是 200。

实验 ② · 位宽推导与防溢出

把 sum 从 u8 换成 u9，同样的两个数相加，就能保住进位。

prismtypes.prism
module wide_add {
    a   : Signal<u8>
    b   : Signal<u8>
    sum : Signal<u9>
    sum = a + b
}
▸ wide_run
cycle a b sum 0 200 100 300 1 255 255 510 # u9 上限 = 511，恰好容得下

Prism 的加法自动扩位规则是 add_width(a, b) = max(wa, wb) + 1——两个 N 位数相加结果需要 N+1 位才能保住进位。当你把结果赋给 Signal<u9>，右侧推位宽正好是 9，两边对齐；赋给 Signal<u8>，就是"结果被截到 8 位"——回到实验 ① 的回绕。

实验 ③ · i1 只能取 {−1, 0}

这条规则是补码数学的直接后果，写位向量时容易忘。

prismtypes.prism
module i1_gate {
    a  : Signal<i1>
    b  : Signal<i1>
    y  : Signal<i1>
    y  = a & b
}

run i1_run of i1_top {
    stim : {
        a, b = {
             0,  0,
             0, -1,
            -1,  0,
            -1, -1,
        }
    }
    ...
}
▸ i1_run
cycle a b y 0 0 0 0 1 0 -1 0 2 -1 0 0 3 -1 -1 -1

stim 表现在只写值、按列头对号——把 i1_run 表里 a 列的某个 0 改成 1，编译器会立刻逮住：

▸ typecheck 报错
[err] [run i1_run] stim 向量0 'a'=1 越界（端口位宽 i1，范围 [-1,0]）
什么时候用 i1？

仓库惯例：谓词/条件码用 i1（a == b 结果是 −1/0），控制位用 u1（en、valid、sel 是 0/1）。这样代码里 if en 与 if (a==b) 走的是两条不同的判等通路，读起来不会混。

实验 ④ · 三元运算符 ? : :

Prism 的表达式支持软件里常见的三元条件——不需要写 mux() 函数。

prismtypes.prism
module bool_flag {
    en : Signal<bool>
    x  : Signal<u8>
    y  : Signal<u8>
    y  = en ? x : 0
}
▸ bool_run
cycle en x y 0 1 42 42 # en=1 → 走 x 1 0 42 0 # en=0 → 走常量 0 2 1 255 255

三元运算符链式右结合——写 c1 ? e1 : c2 ? e2 : e3 就是一个 2 级 mux，不需要括号。

实验 ⑤ · 常量：0x、0b、十进制

Prism 支持 C 风格的字面量：0x... 十六进制、0b... 二进制、无前缀是十进制。

prismtypes.prism
module hex_lit {
    x   : Signal<u16>
    y   : Signal<u16>
    y   = (x & 0x00FF) | 0xFF00
}

run hex_run of hex_top {
    stim : { x = {
            0x1234,  // 4660
            0xABCD,  // 43981
            0x0000,
        }
    ...
}
▸ hex_run
cycle x y 0 4660 65332 # 0x1234 → 0xFF34 1 43981 65485 # 0xABCD → 0xFFCD 2 0 65280 # 0x0000 → 0xFF00

表里的 y 用十进制打印（Prism show 默认十进制；要十六进制输出可以在 show 里加一条 fmt 串——那是后面第 3 集的内容）。

看一眼生成的 SV

三份 module 各截一段核心，看看类型系统怎么下降到 SystemVerilog：

systemverilogadder.sv · 3 段核心
// u8_add: u8 + u8 → u8 — 结果截到 8 位
module u8_add_rtl (...,
  input  logic [7:0] a,
  input  logic [7:0] b,
  output logic [7:0] sum);
  assign sum = (a + b);       // SV 自动截位

// wide_add: u8 + u8 → u9 — 结果保 9 位
module wide_add_rtl (...,
  input  logic [7:0] a,
  input  logic [7:0] b,
  output logic [8:0] sum);
  assign sum = (a + b);

// i1_gate: 1 位有符号 AND — SV 侧就是 [0:0]
module i1_gate_rtl (...,
  input  logic [0:0] a,
  input  logic [0:0] b,
  output logic [0:0] y);
  assign y = (a & b);
类型 → SV 的映射

Signal<u8> → logic [7:0]；Signal<u9> → logic [8:0]；Signal<i1> → logic [0:0] 且 tb 侧带 signed。符号性不改变 SV 位宽——它只影响解释与打印。

小结

这一集我们钉住了 Prism 的四件事：

  1. 四层骨架：module / @schedule / design / run——算法与调度分层。
  2. 类型谱系：u<N> / i<N> / bool——前缀决定符号，N 决定位宽。
  3. 位宽推导：加法结果 max + 1，赋值目标位宽决定截断或保住。
  4. 语法要点：端口一行一个、常量支持 0x/0b/dec、条件走 ? :、i1 陷阱。
